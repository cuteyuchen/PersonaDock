PersonaDock

本地优先、跨 Agent 的 AI 人格控制平面。创建或接管 Canonical Persona，通过原生 Adapter 安全部署到 Hermes 与 OpenClaw，并治理共享 Memory、Session Summary、快照、回滚和信任。

安装

Linux / macOS

curl -fsSL https://raw.githubusercontent.com/cuteyuchen/PersonaDock/main/install.sh | sh
personadock --version
personadock doctor --json

Windows PowerShell

irm https://raw.githubusercontent.com/cuteyuchen/PersonaDock/main/install.ps1 | iex
personadock --version
personadock doctor --json
Canonical Persona v3
结构化人格、来源、置信度、行为规则和确定性场景测试。
Native Adapters
Hermes Profile 与 OpenClaw Agent/Workspace，本机、Docker 和 SSH。
Governed Sync
Memory 与 Session Summary 默认审核，支持冲突、来源和循环抑制。
Safe Lifecycle
Plan、Snapshot、Apply、Verify、Rollback 和 Journal。
Trust & Backup
PersonaPack Ed25519 签名与 AES-256-GCM 私有备份。
Portable
五平台独立程序、Character Card 和稳定 Adapter API 1.0。

快速开始

personadock skill install --target codex --scope global
personadock init ./xiaoyou --id xiaoyou --name 小柚
personadock validate ./xiaoyou
personadock test ./xiaoyou
personadock pack ./xiaoyou --output ./xiaoyou.personapack

安全边界

PersonaDock 不要求 Fork、PR 或上传人格。原始聊天、设计笔记和未审核候选默认留在本地；认证、原始 Session、Transcript 和运行时 State 不进入 PersonaPack，也不会跨运行时同步。

Hermes 与 OpenClaw 默认使用平台原生 CLI。旧文件系统直写仅作为显式迁移兼容模式保留。
